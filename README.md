NeoCardioPredict
Machine Learning Approach Using Statistical Models to Predict Cardiac Arrest in Newborn Babies

NeoCardioPredict is a healthcare-focused machine learning web application developed using Django and statistical machine learning models to predict the risk of cardiac arrest in newborn babies based on medical parameters and patient data.

The project aims to support early diagnosis and assist healthcare professionals by providing prediction results through a simple web-based interface.

Predicts cardiac arrest risk in newborn babies

Installation Guide

Clone Repository
git clone https://github.com/Naveen4676/NeoCardioPredict.git
Move Into Project Folder
cd NeoCardioPredict
Create Virtual Environment
python -m venv venv
Activate Virtual Environment
Windows
venv\Scripts\activate
Linux/Mac
source venv/bin/activate
Install Dependencies
pip install -r requirements.txt
Run Server
python manage.py runserver
